# 东山有戏：这关一起过

**公开脱敏源码版 · 持续开发**

社团主题视觉小说与关卡编辑小游戏：双角色篇章、剧情选择、修路/推箱/机器人试跑、地图编辑、草稿与存档。使用者主导制作，Codex协助程序和内容迭代。

## 打开工程

使用团结引擎1.6.12 / 2022.3.61t13打开仓库根目录，打开Assets/Scenes/Club.unity并播放。UI/剧情主要由C#和Resources下JSON组织。

## 公开版的不同

私人录像、含二维码和联系方式的原海报、基于真人照片的角色图及其参考提示不纳入此仓库。缺失角色图使用新写的程序化占位图，招新界面显示示例图及“公开版不提供群号”，录像入口改为公开版说明。游戏流程和返回入口保留。原本机工程未改成此脱敏版本。

字体保留对应来源和许可。本次只保留不含私人联系方式的背景/桌面道具图；未对第三方内容作统一自有授权。

## 继续开发

后续可用确认可以公开的原创角色和海报替换占位图，并补充试玩视频。此次公开版的编译检查与扫描见PUBLICATION.md；没有把原私有素材版本的验收结果冒充为公开版全流程实机验收。
